## Linear sketching

- how $\rank(x)$ can be computed as an inner product $c_x^Tf$ where $f$ is the frequency vector and $c_x$ is a vector s.t. 

$${c_x}_i = 
\begin{cases}
  1 & \text{ if } i \leq x \\
  0 & \text{ otherwise}
\end{cases}
$$

- linear sketch $s = Af$ where $A$ is some matrix and we have $s \in \R^k$ for $k < n$

- we can recover $\rank(x)$ iff $c_x^T = \alpha^T A$
  - since then $\rank(x) = \alpha^Ts$
  - on the other hand if it is not the case, it means that $c_x^T \notin \row(A)$
    - use the obs that $v \in \ker(A)$ means that $c_x^T v = 0$ if $c^T_x$ is in row space but if not, then there exists $v$ in kernel such that $c_x^T v \neq 0$)
    - but then $s = Af = A(f+v)$ but $\rank(f+v) \neq rank(f)$
