# Theory for Spline Sketch

## Rank and quantile

- $rank(j) = |\{x_i : x_i < j\}|$
- $k$-quantile is $j$ s.t. $rank(j)=\lceil kn \rceil$

## Streaming algorithm

- data arrives in a stream $x_1,\ldots,x_n$
- we cannot use all the data at the same time to compute our metric since the stream is too big
- we need to compute a *sketch* in an online manner (it needs to be updatable as new elements arrive)
